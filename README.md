# video-codex

## Монтаж разговорных Reels

Перед монтажом прочитай этот файл и бриф к ролику. Готовый ролик Александры о Дали задаёт визуальный стиль. Для каждой новой истории выбирай кадры из её собственных исходников и определяй точки склеек по речи. Сохраняй три узнаваемые черты референса: заголовок держится поверх первой склейки, небольшие субтитры идут в ритме речи, а вставка появляется в тот момент, когда меняет понимание фразы.

### Как выбрать следующий кадр

Сначала собери рассказ по голосу. Отметь, где возникает вопрос, где зрителю понадобится увидеть конкретную деталь и на какой реплике раскрывается ответ. Это ориентиры для монтажа. Длина эпизодов и число вставок зависят от нового материала.

| Момент в речи | Решение при монтаже |
| --- | --- |
| Первая фраза вызывает вопрос | Начни прямо с действия или реплики. Поставь короткий заголовок, который можно понять без предыстории. Если под ним меняется кадр, оставь заголовок на том же месте до конца чтения. |
| Автор указывает на конкретную вещь, человека, место или действие | Дай зрителю увидеть то, о чём он только что услышал. Подведи смену кадра к ключевому слову. Оставь вставку на время, нужное, чтобы рассмотреть важную деталь, и продолжай голос поверх неё. |
| Кадр содержит ответ на вопрос из начала | Прибереги его до реплики-раскрытия. Например, в истории о съёмке можно показать процесс, пока автор объясняет замысел, а готовую фотографию открыть на словах о результате. |
| Смысл фразы передаёт лицо, пауза или жест | Останься с автором. Для реакции выбери более крупный план, для жеста — план, где видны руки. Несколько предложений могут прозвучать в одном кадре. |
| Мысль закончена | Дай прозвучать последнему слову, оставь значимую реакцию и заверши ролик. Удали техническую заставку редактора. |

Основной переход — прямая склейка. Если подходящей вставки в исходниках нет, сохрани план автора. Для дополнительного движения используй аккуратное укрупнение, когда оно помогает рассмотреть деталь.

### Типографика референса

| Элемент | Как воспроизвести |
| --- | --- |
| Основной заголовок | Компактный блок примерно в две строки, близко к середине вертикального кадра, ниже лица. Основная часть набрана плотным жирным светлым шрифтом. Проверь читаемость на каждом фоне, через который проходит заголовок. |
| Акцент внутри заголовка | Выдели короткий смысловой фрагмент рукописным наклонным начертанием со светлым и бордовым контрастом. Так в референсе оформлен конец вопроса. В новой фразе акцентируй слова, на которых держится интрига. Собери оба начертания в один заголовок. |
| Субтитры речи | Второй, заметно меньший слой. По одному белому слову без плашки в верхней левой части кадра. Слово меняется на произнесении, позиция остаётся стабильной. Задай одинаковые отступы на всех планах и проверь синхрон после финальной нарезки. |

Пока гарнитуры определены по внешнему виду. Когда автор передаст файлы шрифтов и скриншоты, зафиксируй для каждого слоя конкретную гарнитуру и начертание. По скриншотам уточни размер относительно кадра, переносы, отступы и оформление бордового акцента. Проверь символы языка ролика, включая кириллицу для русских титров.

### Проверка готового ролика

1. Посмотри начало без звука. Успеваешь прочитать весь заголовок, даже если под ним уже сменился кадр?
2. Проверь вставки вместе с речью. Видна ли нужная деталь в момент упоминания? Сохраняется ли интрига до реплики с ответом?
3. Прослушай склейки отдельно. Сохрани окончания слов, естественные паузы и разборчивость голоса поверх музыки.
4. Открой экспорт на телефоне. Проверь читаемость обоих слоёв, синхрон слов, лицо и жесты с учётом интерфейса Reels. Для качественного вертикального исходника ориентир — MP4, 1080×1920 и частота кадров исходника, если бриф не задаёт другую.
