# video-codex

## Кодекс монтажа разговорных Reels об искусстве

Перед монтажом нового ролика открой этот README и сверься с задачей автора. Здесь собраны приёмы из ролика Александры о Сальвадоре Дали и Гале. Используй их для похожих историй. Если в брифе указан другой стиль, язык или формат, следуй брифу.

### Как собран референс

Таймкоды приблизительные. Файл длится 1:05,7, формат вертикальный, 30 кадров/с.

| Время | Что видно | Как применить в новом ролике |
| --- | --- | --- |
| 0:00–0:05 | Александра уже в кадре. Поверх видео вопрос о том, только ли талант сделал Дали великим. Примерно через секунду на весь экран появляется его портрет. Вопрос остаётся и при возвращении к Александре. | Начинай сразу с вопроса, в котором зрителю хочется разобраться. Покажи героя истории при первом упоминании. Дай дочитать заголовок поверх склейки. |
| 0:06–0:10 | Крупно видна обложка книги, затем Александра держит её в руках. На словах о «Постоянстве памяти» появляется сама картина с мягкими часами. | Привязывай вставку к конкретным словам. Когда зрителю называют работу, дай ему увидеть деталь, по которой её можно запомнить. |
| 0:10–0:18 | Возврат к Александре. После вопроса о том, что сделало Дали легендой, появляется чёрно-белая фотография Дали с Галой. | Прибереги изображение второго героя до поворота в рассказе. Преждевременная вставка выдаст ответ. |
| 0:18–1:03 | Большую часть времени в кадре Александра. Меняются крупность, положение рук и выражение лица. Слова вверху продолжают сменяться. | Когда рассказ переходит к личному выводу, оставь зрителя с автором. Укрупни кадр на важной фразе, отойди шире, если смысл передаёт жест. |
| Последние ≈2 с | Чёрная заставка CapCut. | Для публикации заканчивай на последней осмысленной реплике или реакции. При экспорте убирай техническую заставку редактора. |

### Текст и движение

- **Заголовок.** Один короткий вопрос в две строки, примерно посередине по высоте. В референсе основа набрана плотным светлым шрифтом, а последние слова выделены контрастным рукописным начертанием с бордовым акцентом. Ставь вопрос чуть ниже лица и проверь его на обоих кадрах склейки.
- **Субтитры.** Второй слой — небольшие белые слова без плашки в верхней левой части кадра. Для такого же эффекта закрепи одну позицию и меняй слово в момент произнесения. Сохраняй обычный регистр и проверяй имена, даты и названия картин вручную. Язык титров бери из задачи.
- **Шрифты.** Точные гарнитуры по готовому видео не установлены. Подбирай по рисунку букв. Для русского текста проверь кириллицу, особенно рукописное начертание.
- **Склейки и анимация.** Движение уже дают мимика, жесты, смена крупности и слов. Основной переход — прямая склейка. Если нужен дополнительный акцент, выбери один приём для конкретной фразы, например плавное приближение к детали картины.
- **Голос и паузы.** Сначала собери цельный рассказ. Убирай дубли, сохраняй окончания слов и паузу перед раскрытием. При показе портрета или картины продолжай речевую дорожку. Если в исходниках есть музыка, подбирай её громкость по разборчивости тихих слов.

### Перед сдачей

1. Посмотри первые пять секунд на телефоне без звука. Понятно, кто герой и какой вопрос останется открытым?
2. Прослушай склейки с закрытыми глазами. Фразы должны звучать естественно, без срезанных слогов и скачков громкости.
3. Проверь совпадение слов с речью и момент появления каждой картины или фотографии. Убедись, что лицо, важная деталь и титры видны с интерфейсом Reels.
4. Для нового вертикального исходника подходящего качества экспортируй MP4 9:16, ориентир — 1080×1920. Сохраняй частоту кадров исходника, если бриф не требует другой. Проверь последние секунды уже в готовом файле.
