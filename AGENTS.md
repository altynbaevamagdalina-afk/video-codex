# Работа с клиентами

1. Определи клиента по задаче. При неоднозначности уточни имя у Магдалины.
2. Прочитай обязательные правила в [README.md](README.md), затем индивидуальный профиль клиента.
   - Александра Брусникина — [clients/alexandra.md](clients/alexandra.md).
   - Людмила — [clients/ludmila.md](clients/ludmila.md).
3. Перед монтажом изучи актуальное ТЗ, исходники и брендовые материалы клиента на Google Диске. Используй материалы, шрифты, дизайн и референсы этого клиента.
4. Сохраняй согласованные индивидуальные правки только в файле клиента. Правила, явно согласованные для всех, сохраняй в README.md.
5. Для новых клиентов создавай в `clients/` файл по имени клиента, например `clients/anna.md`. Используй строчные латинские буквы, цифры и дефисы. Если утверждены настройки субтитров для автоматизации, добавь JSON в комментарии `video-codex:` по образцу профиля Александры. Тень задаётся долей от 0 до 0,15.
6. Применяй автоматическую обработку к разговорным исходникам с синхронизированным голосом. Проверяй результат по общему стандарту и согласовывай монтаж с Магдалиной перед финальным экспортом.
